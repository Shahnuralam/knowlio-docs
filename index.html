Everything a docs site needs

No page builder, no external service, no dependency on another plugin.

Full-screen admin

A distraction-free authoring workspace that takes over wp-admin so you focus only on writing.

Rich-text editor + media

The full WordPress TinyMCE editor with media-library image upload — headings, lists, links, images.

Paste from Word & Docs

Paste straight from Microsoft Word or Google Docs — formatting is kept, unsafe markup is stripped.

One shortcode front end

[minidocs] renders the whole site — landing page, categories, articles and search.

Layout presets

Switch the whole front end between sidebar, wide, boxed and magazine layouts — no theme edits.

Auto table of contents

A table of contents is built automatically from each article's headings, with scroll highlighting.

Responsive images

Adds srcset, sizes and lazy loading, so readers never download a full-res file to view it small.

Built to WP standards

Escaped output, sanitised input, a nonce & capability check on every write, and prepared SQL.

Search & reading time

Built-in article search, view counts, estimated reading time and copy buttons on code blocks.

Live in three steps

From activation to a published knowledge base in a few minutes.

Write your docs

Open the MiniDocs menu, create categories, then write articles in the rich-text editor.

Drop the shortcode

Create a page and add [minidocs]. It renders every state from the page URL.

Pick a layout

In MiniDocs → Settings, choose your knowledge base page and a layout preset.

// On any WordPress page:
[minidocs]

// That single shortcode renders the landing page,
// category pages, single articles and search.

Four layouts, one click

Set the width and column structure of the whole front end from the settings screen.
